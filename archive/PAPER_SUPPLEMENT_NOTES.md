# Paper supplement notes

What was added to support `ConferencePaper_DRAFT.md`, and why, working from the
draft's own needs and the existing `results/`/`figures/` trees. **No experiments
were rerun.** Everything below is a restyled, recombined, or reduced view of
numbers already produced and cited by the thesis pipeline (`experiments/stats/`,
84/84 tests passing) — see each script's docstring for the exact provenance
chain.

## Why these four items, not others

The paper draft (`ConferencePaper_DRAFT.md`) is a 6-8 page, two-column IEEE
submission with **zero figures currently embedded** and one condensed table
(Table I, the 8-row hypothesis-verdict summary). The thesis's own figure set
(9 figures, one per tier/regime, Spanish labels) would not fit the page budget
if reused as-is — a 2x2 grid of CD diagrams alone would need ~1.5 columns at
thesis sizing. So the gap wasn't "no figures exist," it was "the existing
figures are the wrong shape for this venue." That's what the four new figures
fix. The two supplementary tables fill a different gap: specific claims in
the paper's prose (GA's dominance in Sec. V-A, the la40 anomaly in Sec. V-D)
are asserted with only an aggregate or a one-sentence summary — a reviewer
asking "show me" currently has nowhere to look that isn't the full thesis.

| File | What it is | Why it's needed for the paper specifically |
|---|---|---|
| `Fig_P1_h1_rpd_overview.png/pdf` | Grouped bar: mean RPD by method (RL, best-PDR, GA, CP-SAT), one group per instance family (JSSP / FJSP-synthetic / FJSP-Brandimarte) | **New content, not in the thesis at all.** Section V-A's H1 discussion cites RL=24.82%, best-PDR=18.96%, GA=5.52%, CP-SAT≈0% (JSSP) and 48.76%/89.65% (FJSP arms) purely in prose — there was no single visual anywhere (thesis or paper) putting all three instance families and four methods side by side. | `Fig_P2_h2_cd_grid.png/pdf` | 2x2 grid combining all four Friedman-Nemenyi critical-difference diagrams (H2, one per size tier) | Compacts the thesis's four separate figures (`Fig_6.3.1a-d`, each its own PDF) into one page-budget-fitting panel. English labels, smaller type, tighter spacing — same underlying `friedman_test`/`critical_difference` calls, same numbers. |

## What was *not* added, and why

- **No new experiments were run.** Every number above already exists in
  `results/` or `experiments/results/`; the "genuine gap" identified was
  presentation (page budget, missing overview visual, prose-only claims), not
  missing data.
- **No multi-seed re-analysis for the κ ablation** — the paper's own
  "Threats to validity" paragraph (Sec. VI) already discloses the single-seed
  limitation candidly; fabricating a supplementary table implying more
  seeds exist would misrepresent the actual experimental record.
- **No architectural-ablation figure** — Sec. VI and VII both explicitly flag
  this as unrun future work, not a documentation gap; there is no result to
  visualize.

## Regenerating this supplement

```bash
cd "code"
./.venv/Scripts/python.exe scripts/generate_paper_figures.py --out-dir ../figures/paper
./.venv/Scripts/python.exe scripts/export_paper_supplement_tables.py --out-dir ../figures/paper
```

Both scripts are deterministic given the same `experiments/results/` /
`results/tablas/` state — no randomness, no dependency on wall-clock time.
